# Decision question

Should the founder commit to a fixed lease now, or test demand first?

## Options considered

1. Commit to a lease and invest in a permanent location.
2. Run a two-week pre-order pilot using existing facilities.
3. Stop the idea until more information is available.

## Selected option

Option 2: run the [two-week pre-order pilot](../options/two-week-pilot.md). This is a provisional choice, not a model instruction.

## Rationale

The [weekday lunch demand assumption](../assumptions/weekday-lunch-demand.md) is high impact and highly uncertain. A bounded pre-order test can reveal paid behaviour at lower commitment than a lease.

## Review trigger

Revisit the decision after the experiment has completed and the success criteria have been assessed.

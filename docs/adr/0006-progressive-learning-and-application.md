# ADR-0006: Progressive learning and applied competence

- **Status:** Proposed
- **Date:** 2026-11-25

## Context

Founders should encounter relevant concepts when they become useful, rather than being required to study every framework upfront. Spaced repetition can support recall, but remembering a definition does not prove the ability to apply it.

## Decision

Design a progressive teaching system that introduces relevant concepts in context, records learning events and schedules retrieval practice using an FSRS-inspired approach where appropriate. Track knowledge recall separately from applied competence, which requires scenario work, founder evidence and review.

## Consequences

- Store source and version for each concept.
- Do not copy copyrighted books or proprietary course materials without permission.
- Measure recall, transfer and application separately.
- Scheduler choice and learning efficacy require user testing; no learning gains are claimed yet.
